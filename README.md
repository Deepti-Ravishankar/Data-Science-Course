# Data Science Course 🚀

Welcome to my learning repository!  
This is where I document my journey through the **Data Science course by IIT-Guwahati**, exploring the essential tools and concepts that power today’s data-driven world.

## 📚 What I’m Learning
- **Excel**: Building a strong foundation in data handling and visualization.  
- **Python**: Unlocking the power of programming for analysis, automation, and machine learning.  
- **Power BI**: Designing interactive dashboards to tell compelling data stories.  
- **SQL**: Querying and managing databases to uncover insights.  
- **Statistics & Machine Learning**: Understanding the math behind predictions and models.  

## 🌟 Why It’s Exciting
Data Science isn’t just about crunching numbers—it’s about solving real-world problems and creating meaningful impact.  
For me, the excitement lies in applying these skills to **creative domains like fashion**:
- **Trend Forecasting**: Using ML models to predict upcoming styles.  
- **Personalized Styling**: Leveraging data to recommend outfits tailored to individual preferences.  
- **Sustainable Design**: Applying analytics to reduce waste and promote eco-friendly fashion choices.  

Every commit here represents a step forward in mastering these skills and experimenting with projects like **Iris classification**, **Titanic survival prediction**, and beyond.  

## ✨ My Vision
This repository is more than coursework—it’s a launchpad for blending **technical expertise** with **creative innovation**. I’m excited to explore how AI/ML can transform industries, starting with fashion, and expand into broader applications.
